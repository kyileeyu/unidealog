멘토링을 받고있다.
사용자가 경험할 수 있는 웹의 구성 요소를 모두 구현해서 라이브러리로 만들어보라는 조언을 들었다.


당장 책부터 샀다.
'UX/UI의 10가지 심리학 법칙'을 샀다.
이거 바이블인것 같다. 나랑 주말마다 만나는 디자이너 언니도 이 책을 대학원생때 한 챕터씩 스터디 했다고 하셨다. 클로드가 알잘딱하게 추천해 준것 같다.

Headless UI
머리가 없는 UI 는 무엇인가. 말그대로 머리(여기서는 스타일링 부분을 말한다)가 없는 UI로 Headless는 **디자인 없이 기능만 제공해주는 라이브러리**이다.


**W3C ARIA APG란?**

- **ARIA**: Accessible Rich Internet Applications
- **APG**: ARIA Authoring Practices Guide
- W3C에서 만든 "웹 컴포넌트를 접근 가능하게 만드는 가이드북"
